# 开发执行步骤

## 开发原则

- **小步推进**：每阶段只做一件事，完成并验证后再进入下一阶段
- **每阶段一提交**：一个阶段完成后在 dev-log 中记录
- **先骨架后血肉**：先搭 HTML 结构 → CSS 样式 → JS 交互 → 数据持久化
- **零依赖**：不引入任何第三方库/CDN，完全离线可用
