# 项目需求文档 — 中国警校考研辅助软件

## 项目概述

一款运行在华为 Mate 60 Pro（鸿蒙系统）上的中国警校研究生备考 PWA 应用，以公安政务极简规范为设计语言，服务于公安考研人群的长期沉浸式学习。

## 用户画像

- 中国警校考研备考学生
- 使用华为 Mate 60 Pro 手机
- 非技术背景
- 独立使用，无需多设备同步

## 功能需求

### 模块一：目标警校规划

- 展示中国公安类研究生院校列表
- 每所院校卡片展示：院校名称、招录专业、历年分数线、考研科目
- 支持单选/多收藏目标院校
- 收藏院校自动汇总至首页顶部置顶
- 支持一键生成对应备考科目清单
- 确认目标后同步至首页倒计时模块
- 院校数据预置内置

### 模块二：学习计划 + 定时提醒

- 四大科目：政治、英语、数学、专业课
- 每条计划：标题、描述、提醒时间
- 支持添加、编辑、删除学习计划
- 到达设定时间时通过系统通知提醒
- 每个计划可设置单次/每日重复

### 模块三：每日学习打卡

- 日历式打卡面板
- 五大打卡分类：政治、英语、数学、专业课、体能训练
- 每项完成点亮对勾
- 底部数据统计：连续打卡天数、月度学习总时长
- 断卡仅温和提示，无负面弹窗

### 模块四：备考倒计时

- 首页顶部醒目显示
- 距考试天数倒计时
- 考试日期从目标院校同步，也可手动调整
- 数字用鎏金强调色

### 模块五：备考日历 + 学习日志

- 重要日程里程碑：四级报名（9/18）、数学建模大赛（11/14 上午 9:00-11:30）、四级口语（11/21）、四级笔试（12/12），每项显示距今天数
- 内置分阶段复习计划建议（四级 / 数学建模各三阶段）
- 学习日志：随时记录学习收获、问题、心情，支持标签（四级/建模/考研/其他）、删除
- 数据存本地 IndexedDB（studyLogs 存储）

### 模块六：解锁学习提醒

- 离开屏幕 ≥5 分钟再回到 App（解锁或切回）时，全屏弹出学习提醒：警句 + 距考研天数 + 今日打卡进度
- 短蜂鸣 2 声 + 振动，一键跳转「打卡」或「写日志」
- 「今天不再提醒」当天静音，次日自动恢复；可手动开关（首页卡片）
- 说明：受系统限制，任何 App 都不能在锁屏上强制自动弹出；需将 App 留在前台锁屏，解锁后即弹出

## 非功能需求

- **平台**: 华为 Mate 60 Pro，鸿蒙系统，曲面大屏
- **离线可用**: 无网络时也能正常使用
- **数据隐私**: 所有数据仅存本地，不上传服务器
- **安装方式**: 浏览器访问后添加到手机桌面
- **语言**: 简体中文
